## T6 的三处

| 位置 | 学习者答的 |
|---|---|
| `__init__` 第一行 | 没调用 `super().__init__()` |
| 参数个数统计 | `len(net.parameters())` 只能数张量，要累加 `numel` |
| 换权重 | `.data = ...` 换了存储，要用原地改写 |

第二处说得略松：`len()` 对生成器是直接抛 `TypeError`，不是"数出来只有张量数"。
方向对，验收按对算。

## 三处小问题（不影响通过）

1. `count_params` 里用 `sum = 0` 当累加变量，遮蔽了内置 `sum`。改 `total` 更好
2. T1 的 `forward` 写成一行嵌套 `self.out(relu(self.hidden2(relu(self.hidden1(x)))))`。
   功能对，但调试时看不出中间形状，拆三行更利
3. `forward` 只注了参数类型，没写 `-> torch.Tensor`

## 实现观察

三处体现出理解而非试错：

- **T2 共享参数**用的是"同一个层对象在 `forward` 里调两次"，不是建两个层再赋同一个
  `nn.Parameter`。后者也能过断言，但共享的语义不完整
- **T4** 用了 `with torch.no_grad()` 加 `t[t.abs() < 5] = 0`，没有绕开叶子张量的限制
- **T5** 用 `nn.ModuleList` 装 `nn.Sequential(nn.Linear, nn.ReLU)`，比装裸 `nn.Linear`
  再在前向里补 ReLU 多走一步，把"层 + 激活"当整体，读起来更清楚
