# 工具链与教学法调整

开课前的第二轮准备。学习者还没开始 A0，但这一轮里他提了六条反馈，每条都改了东西。

## 目标

把学习环境、防溜号机制、讲义写法都调整到学习者的实际背景上。

## 讲了什么

无授课。按学习者提出意见的顺序记。

### 一、讲义不该塞完整代码

原 A0 讲义给了 `hello_tensor.py` 和 `sin.py` 的完整代码，学习者指出这等于让他粘贴，
而且没有解释。改法：

- A0 重写。先讲四个 Python 约定（import、属性与方法、缩进、注释），
  给文档链接表，两个任务都改成"要求 + 骨架（关键行留 `____`）+ 期望输出 + 分级提示"
- `AGENTS.md` 加硬规则：**讲义里不许出现可以直接复制粘贴的完整实现**。
  判定标准是把讲义给一个只懂语法、不认识库的人，他能不能不查任何东西就抄下来跑通
- 顺手修了 A1 讲义里剧透 B06 的地方（原第 5.3 节直接给了 `data_iter` 的完整实现）

### 二、讲解的边界

连续两条反馈：不要假设他会 Python 的魔法约定，也不要假设他是 Linux 小白。

- 写进 `AGENTS.md`：Linux 与 shell 层（命令行、git、PATH、权限、进程、SSH、nix）当熟，
  直接给结论；Python 语言本身与 torch/matplotlib/pandas/numpy 的 API 当新手，逐个交代
- A0 里删掉 `mkdir -p`、`git add/commit`、`less` 退出键的解释

### 三、防溜号机制

学习者要求设时间预期、用扬声器提醒，并给出流程：后台 job 当定时器 → 到点问进度 →
五分钟没回话就响铃。他补充了两条背景：通知由 noctalia 负责、合成器是 umbriel，
以及他的作息与工作时段（记在 `LOCAL.md`，不入库）。

- 写了 `tools/remind.sh`
- 写成 skill `skills/d2l-study-reminder/SKILL.md`，校验通过后软链到 `~/.dsh/skills/`，
  已在会话的技能目录里生效

### 四、TTS 装在哪

装 piper 时先进了 home-manager，学习者指出这种只服务一个项目的工具该放项目 devShell。
改成仓库的 `tts` devShell 并从 home-manager 撤出。
