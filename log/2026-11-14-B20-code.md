## 结果

7 项断言全过。一轮返工：`to_onehot` 的 `one_hot` 没传 `num_classes`。

## 做对的地方

- `rnn_forward`：返回 `(outputs, (H_new,))`，`outputs` 是 logits，与 B19 的只返回状态序列不同。
- `grad_clipping`：先累加平方和、`.item() ** 0.5` 开方、用范数判断与缩放、返回范数。四次迭代走到正确版本
  （`norm / size` → `(sum g)**2 / numel` → 这个）。
- `train_rnn`：换成 SGD 后一次通过。相邻采样的 `state = (state[0].detach(),)` 位置对，
  随机采样每批重置对，`Y.t().reshape(-1)` 与 `torch.cat(outputs, dim=0)` 对齐。
- T5 三处全找对，注释里写清了改法（"需要转置"、"不需要自己softmax"、"缩放错东西了 要缩放梯度"）。

## 返工的一处

`to_onehot` 写成 `F.one_hot(X.long())`，没传 `num_classes`。

后果：最后一维取这一批的最大索引 +1。词表 4、这一批只有 0 和 1 时输出 `(2,3,2)`，
`unbind` 后每步 `(2,2)`，与 `W_xh` 的 `(4,8)` 乘不起来：

```
mat1 and mat2 shapes cannot be multiplied (2x2 and 4x8)
```

原来的测试语料 `"abcd" * 200` 每批 48 个字符必然含全部四个，所以断言一直没暴露。
补了一条用「不含最大索引的批量」测的断言。

## 出题时的问题

学习者指出：「问题是你也没要求。在要求下怎么写都是没问题的」。

查题面 T1，验收表里确实写了「每个元素形状 `(batch, vocab_size)`」，
提示里也写了 `one_hot(t, num_classes)`，但没排除「`vocab_size` 按这批最大索引算」这种读法。
已在 docstring 里加两句说死：

> vocab_size 是函数参数，不是「这一批里出现过的最大索引 + 1」。
> 某一批只出现了 0 和 1 时，输出仍然必须是 (batch, vocab_size)。
