## T5 的三处

|---|---|
| 3×3 卷积 | 缺 `padding=1` |
| 5×5 卷积 | 缺 `padding=2` |
| `torch.cat([...])` | 缺 `dim=1`，默认在 batch 维拼接 |

## 两处可改进

1. **`make_nin` 里 `pool` 实例复用三次**。池化无状态，可行；换成 BN 这类带 buffer 的层
   会共享统计量，必须每次新建。
2. **位置参数与关键字混用**。`nn.Conv2d(64, 192, 3, 1, 1)` 与
   `nn.Conv2d(96, 256, 5, padding=2)` 在同一文件里并存。

## 一个可读性建议

`make_googlenet` 展平成一个 22 层 `Sequential`，b1–b5 的边界不可见。分开写更能体现"五个模块"。
