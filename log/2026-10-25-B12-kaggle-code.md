## 讲了什么

### 调试过程里撞的八次报错

这一章是整个课程里撞报错最多的一章，全部集中在数据处理：

1. `Columns must be same length as key` —— `data[category_cols] = get_dummies(...)`，
   左边 43 列右边 200 多列
2. `InvalidIndexError` —— `DataFrame` 不支持 `[:, -1:]`，要 `.iloc[:, -1:]`
3. `could not determine the shape of object type 'DataFrame'` —— `torch.tensor(DataFrame)`
   要加 `.values`
4. `fillna(0)` 单独一行没用 —— pandas 默认不原地改
5. 353 列而不是 330 —— `fillna(0)` 写在 `get_dummies` 之前，类别列的缺失被填成 0
   之后又当成新类别
6. `size of tensor a (64) must match (1460)` —— 批循环里用全量标签算损失
7. 训练误差 8.15 —— `torch.optim.Adam` 漏了 `lr`
8. 验证误差 1.25 —— `get_k_fold_data` 把第 i 折当训练集了，训练/验证反了

第 8 次是真正花时间的一个：每折只用 292 个样本训练，两个误差都在 1.24 左右
（相当于全预测成均价）。断言当时没抓到，因为只查了"训练+验证=1460"与
"各折验证拼起来覆盖全部"，没查谁大谁小。已补一条。

### T7 第三处的理由

题目提示只写了"先填缺失再 one-hot 会影响类别特征"，学习者给出的理由是
"先 one-hot，否则 0 也会被 one-hot 拆开"——点出了机理，比提示更准。
这正是他撞到 353 列那次的直接原因。

### 两次出题问题

- **T2 没说清训练集要切掉标签**（`SalePrice`）
- **T4 说"损失用 log_rmse"表述不清**：反向传播用 `nn.MSELoss`，记录的指标才是 `log_rmse`

另有三次说明补全：`divmod` 的含义、`k_fold` 的步骤、类型注解给全。
