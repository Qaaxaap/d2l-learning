# 开发机换系统后的环境验证

## 背景

开发机在 2026-11-11 从 Arch Linux 换成了 NixOS。之前记录的
「Arch + 系统 python 3.14 + python-pytorch-cuda」全部失效，要重新核对一遍。

## 换之前与换之后

| 项 | 之前（Arch） | 现在（NixOS） |
|---|---|---|
| 系统 | Arch，内核 7.2.6 | NixOS，内核 6.18.62 |
| python | 3.14.7（`/usr/bin/python3`）| 3.13.17（`/run/current-system/sw/bin/python3`）|
| torch | 2.14.0 | 2.11.0+cu128 |
| torchvision | 0.29.0a0 | 0.26.0+cu128 |
| 包来源 | pacman 的 `python-pytorch-cuda` | nix profile（`~/nix` 的 `modules/packages.nix`）|
| GPU 驱动 | 615.71.09，CUDA UMD 13.4 | 595.71.05，CUDA UMD 13.2 |
| 磁盘 | 根分区 200G，剩 48G | `/home` 300G，剩 89G |
| tmux | 有 | 无 |
| miniforge | `/opt/miniforge` | 无 |

仓库的 `flake.nix` 本来就写好了：devShell 只装 uv/just/git，解释器与科学包在 nix profile。
这次不用改它。

## 缺的包

扫了 `exercises/`、`tools/`、`solutions/`、`work/` 全部 `.py` 的 import，
第三方包只有五个，缺两个：

| 包 | 状态 | 被谁用到 |
|---|---|---|
| matplotlib | 缺 | B09 的画图题与断言 |
| pandas | 缺 | B12 的房价题与断言 |
| numpy / torch / torchvision | 有 | |

`just env` 还会报 `tqdm` 未安装，但仓库里没有任何一处 import 它。
`d2l` 包（第二版官方）也没装，仓库同样不用。

学习者装完后：matplotlib 3.10.9、pandas 2.3.3、tqdm 4.67.1。
