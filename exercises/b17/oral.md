## 必会

**Q1** AlexNet 相对 LeNet 改了哪四处？哪一处最关键？

<details><summary>参考答点</summary>

| 维度 | LeNet | AlexNet |
|---|---|---|
| 深度 | 2 卷积 + 3 全连接 | 5 卷积 + 3 全连接 |
| 激活 | sigmoid | **ReLU** |
| 正则化 | 无 | **Dropout（两个全连接层后）** |
| 第一层核 | 5×5 步幅 1 | 11×11 步幅 4 |

**最关键的是 ReLU**。B16 实测过：同样的结构用 sigmoid，5 个 epoch 精度恒为 0.10
（等于瞎猜），损失停在 `log(10)`。用 ReLU 能到 0.82。

</details>

**Q2** 输入 `(1, 1, 224, 224)`，依次经过：

```
Conv2d(96, kernel_size=11, stride=4)
MaxPool2d(kernel_size=3, stride=2)
Conv2d(256, kernel_size=5, padding=2)
MaxPool2d(kernel_size=3, stride=2)
```

写出每一步的输出形状。

<details><summary>参考答点</summary>

| 层 | 输出 |
|---|---|
| 输入 | `(1, 1, 224, 224)` |
| Conv 11, s4 | `(1, 96, 54, 54)` |
| MaxPool 3, s2 | `(1, 96, 26, 26)` |
| Conv 5, p2 | `(1, 256, 26, 26)` |
| MaxPool 3, s2 | `(1, 256, 12, 12)` |

两处取整：`⌊(224-11)/4⌋+1 = 54`、`⌊(54-3)/2⌋+1 = 26`。

</details>

**Q3** VGG 的 `conv_arch = ((1, 64), (1, 128), (2, 256), (2, 512), (2, 512))`
里每个二元组的两个数字各表示什么？这个网络展平后的维度是多少？

<details><summary>参考答点</summary>

每个二元组是 `(卷积层数, 输出通道数)`：

- 第 1 块：1 个卷积，64 通道
- 第 2 块：1 个卷积，128 通道
- 第 3 块：2 个卷积，256 通道
- 第 4、5 块：各 2 个卷积，512 通道

5 个块各含一次池化，224 减半 5 次 = 7。
展平维度 `512 × 7 × 7 = 25088`。

</details>

**Q4** NiN 用什么替代全连接层？为什么这样能大幅减少参数？

<details><summary>参考答点</summary>

用 **1×1 卷积**，最后再用**全局平均池化**。

1×1 卷积等价于"通道维上的全连接"：参数只有 `c_in × c_out`。
而普通全连接层的参数是 `(c_in × H × W) × c_out`，多乘了 `H × W`。

NiN 实测 199 万参数，AlexNet 4678 万，VGG-11 1.29 亿。

</details>

## 了解

**Q5** Inception 块里线路 2、3 前面为什么先加一个 1×1 卷积？

<details><summary>参考答点</summary>

**降维（bottleneck）**。

直接对输入做 3×3 或 5×5 卷积，参数量是 `c_in × c_out × k²`，
`c_in` 很大时（比如 192）这个数字很可观。先用 1×1 把通道降到 96 或 16，
再做 3×3 或 5×5，参数少很多，效果接近。

</details>

**Q6** 全局平均池化怎么做？为什么能取代最后的全连接层？

<details><summary>参考答点</summary>

`nn.AdaptiveAvgPool2d(1)`：对每个通道的所有空间位置求平均，输出 `(N, C, 1, 1)`。

前面一个块的输出通道数等于类别数（比如 10），所以每个通道的平均值就是该类别的分数。
不需要再乘一个 `C×H×W → num_classes` 的大矩阵。

**好处**：参数几乎归零，输入尺寸可变。
**代价**：收敛更慢。

</details>

**Q7** Inception 块四条线的输出要拼接，用什么函数？拼哪一维？为什么？

<details><summary>参考答点</summary>

`torch.cat([p1, p2, p3, p4], dim=1)`。

**第 1 维**是通道维（第 0 维是批量）。

拼在通道维是因为四条线输出的是同一批样本、同样的高宽、不同通道的特征图。
按通道拼起来得到"多尺度特征"。拼在批量维会把不同样本混在一起。

</details>
