1. 训练集与测试集的形状各是多少？为什么要合并两边的特征？
2. 为什么标准化要用全部数据（训练+测试）的均值与标准差？
3. 缺失值在数值特征与类别特征上分别怎么处理？

8. `to_csv` 忘了 `index=False` 会怎样？

## 三处要留意

**这一章真正的工作量在数据**。模型只有一个线性层，训练循环与 B06 相比只换了优化器
（SGD → Adam）与评估指标（平均损失 → 对数均方根误差）。所以读的时候把时间放在
数据处理那几节上。

**pandas 是一个新库**。讲义里把用到的每个 API 都讲了（`read_csv`、`dtypes`、`iloc`、
`apply`、`fillna`、`get_dummies`、`values`、`to_csv`），不必去查文档。

**数据已经下载好**，在仓库的 `data/` 目录下。不用自己找。
