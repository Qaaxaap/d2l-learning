## T2 自己判断能不能广播

```python
def safe_broadcast_add(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
```

行为：

- 两个形状可以广播时，返回相加结果。
- 不能广播时，抛 `ValueError`，异常信息里必须包含**第一处不匹配的维度编号**。

维度编号怎么算，分两步，别混：

1. **对齐**：两个形状从最右边一维开始匹配，短的形状缺的那几维在**左边**补 1
2. **编号**：补齐之后两者长度相同，从**左往右**数，最左边是第 0 维，最右边是最后一维

举例：`a.shape == (3, 4)`、`b.shape == (2, 4)`。补齐后长度都是 2，第 0 维上 3 与 2 不匹配，
所以报错信息里要出现 `0`。

再举一个：(3, 4) 与 (1, 4)，第 0 维 3 与 1 中有一方为 1，可以广播，不报错。

形状不同长度时的补齐规则见讲义第 4 节。

抛异常用 `raise`，语法见讲义 2.5 节。

这一题**不许用** `torch.broadcast_shapes` 这类现成的形状工具，也不许直接把两个张量相加了事。
形状对齐、逐维判断、报错信息全部自己写——这道题考的就是广播规则本身。
