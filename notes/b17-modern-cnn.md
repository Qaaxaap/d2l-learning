# B17 四种经典卷积网络

LeNet 之后，卷积网络沿着四条思路演化：**更深**（AlexNet）、**更规整**（VGG）、
**更省参数**（NiN）、**更宽**（GoogLeNet）。

这一章不做训练实验——四个网络都在 ImageNet 尺度上设计，本机用它跑 Fashion-MNIST
只是为了验证结构能前向。重点是**看懂每种设计解决了什么问题**。

## 0 这一单元解决什么问题

B16 的 LeNet 是 1998 年的设计：两个卷积层、三个全连接层、sigmoid 激活。
2012 年之后出现了几个关键改进，这一章的四个网络就是这些改进的代表。

| 网络 | 年份 | 关键改动 | 解决的问题 |
|---|---|---|---|
| **AlexNet** | 2012 | 更深、ReLU、Dropout、更大核 | 深网络训得动 |
| **VGG** | 2014 | 用重复的块搭网络 | 结构可配置、可复用 |
| **NiN** | 2014 | 1×1 卷积 + 全局平均池化 | 全连接层参数太多 |
| **GoogLeNet** | 2014 | Inception 块（多尺度并行） | 同一层里融合不同尺度的特征 |

## 1 AlexNet

### 1.1 它改变了什么

AlexNet 与 LeNet 的原则相同（卷积 + 池化 + 全连接），差别在四处：

| 维度 | LeNet | AlexNet |
|---|---|---|
| 深度 | 2 卷积 + 3 全连接 | 5 卷积 + 3 全连接 |
| 激活 | sigmoid | **ReLU** |
| 正则化 | 无 | **Dropout（两个全连接层后）** |
| 第一层核 | 5×5 步幅 1 | **11×11 步幅 4** |

**ReLU**：B16 的 4.5 节实测过，sigmoid 在这个规模上根本训不动。
书上把这一条列在第二位，实际它是最关键的一条。

**11×11 步幅 4**：ImageNet 的图是 224×224，物体比 28×28 的手写数字大得多，
所以用更大的窗口快速覆盖。步幅 4 让第一层就把尺寸从 224 压到 54。

**Dropout**：两个 4096 维全连接层，参数加起来接近 1 GB。这么宽的层容易过拟合，
所以每个后面接 `nn.Dropout(0.5)`。

### 1.2 结构

```
Conv(96, 11, stride=4)  → ReLU → MaxPool(3, stride=2)
Conv(256, 5, pad=2)     → ReLU → MaxPool(3, stride=2)
Conv(384, 3, pad=1)     → ReLU
Conv(384, 3, pad=1)     → ReLU
Conv(256, 3, pad=1)     → ReLU → MaxPool(3, stride=2)
Flatten → Dropout(0.5) → Linear(4096) → ReLU
        → Dropout(0.5) → Linear(4096) → ReLU
        → Linear(num_classes)
```

**注意 Dropout 的位置**：在 `Sequential` 里写的时候，`nn.Linear` 与 `nn.ReLU` 是分开的两层，
顺序是 `Linear → ReLU → Dropout`。书上 MXNet 的 `Dense(activation='relu')` 把激活折进层里，
torch 里要显式写 `nn.ReLU()`。

### 1.3 形状链（输入 1×224×224）

| 层 | 输出 | 计算 |
|---|---|---|
| Conv 11×11，步幅 4，填充 0 | `(N, 96, 54, 54)` | `⌊(224-11)/4⌋+1 = 54` |
| MaxPool 3×3，步幅 2 | `(N, 96, 26, 26)` | `⌊(54-3)/2⌋+1 = 26` |
| Conv 5×5，步幅 1，填充 2 | `(N, 256, 26, 26)` | 填充保持 |
| MaxPool 3×3，步幅 2 | `(N, 256, 12, 12)` | `⌊(26-3)/2⌋+1 = 12` |
| Conv 3×3，步幅 1，填充 1 | `(N, 384, 12, 12)` | 保持 |
| Conv 3×3，步幅 1，填充 1 | `(N, 384, 12, 12)` | 保持 |
| Conv 3×3，步幅 1，填充 1 | `(N, 256, 12, 12)` | 保持 |
| MaxPool 3×3，步幅 2 | `(N, 256, 5, 5)` | `⌊(12-3)/2⌋+1 = 5` |
| Flatten | `(N, 6400)` | `256 × 5 × 5` |

**形状链里有两次取整向下**，这是最容易算错的地方。用公式
`⌊(n - k + 2p)/s⌋ + 1`，`2p` 是两侧填充之和。

## 2 VGG

### 2.1 块的思想

VGG 的贡献不是某个新运算，而是**把网络写成可配置的块**：

```python
def vgg_block(num_convs, num_channels):
    """num_convs 个 3×3 卷积（填充 1、ReLU）接一个 2×2 最大池化。"""
```

**每个块的规律**：

- 卷积都是 3×3、填充 1 → **高宽不变**
- 块末的池化 2×2 步幅 2 → **高宽减半**
- 块内所有卷积的输出通道数相同

**于是整个网络可以只用一张表描述**：

```python
conv_arch = ((1, 64), (1, 128), (2, 256), (2, 512), (2, 512))
#            ↑卷积层数  ↑输出通道
```

这张表对应的就是 **VGG-11**：1+1+2+2+2 = 8 个卷积层，3 个全连接层。

### 2.2 形状链（输入 1×224×224）

| 块 | 卷积层数 × 通道 | 卷积后 | 池化后 |
|---|---|---|---|
| 1 | 1 × 64 | 224 | 112 |
| 2 | 1 × 128 | 112 | 56 |
| 3 | 2 × 256 | 56 | 28 |
| 4 | 2 × 512 | 28 | 14 |
| 5 | 2 × 512 | 14 | 7 |

展平：`512 × 7 × 7 = 25088`，然后 `4096 → 4096 → num_classes`。

### 2.3 为什么这样设计

**高宽减半、通道翻倍**：每经过一个块，空间尺寸变小一半，通道数变大一倍。
这样每个卷积层的参数量大致相同（`c_in × c_out × 9`，两个通道都变了一倍，乘积涨四倍，
但空间除以四，计算量持平）。

书上的原话是"使多数卷积层都有相同的模型参数尺寸和计算复杂度"。
这是 VGG 能被写成"块 + 表"的前提——每个块只差两个数字。

## 3 NiN

### 3.1 问题：全连接层太贵

AlexNet 与 VGG 的最后几个全连接层占了绝大部分参数。VGG-11 的全连接部分：

```
25088 × 4096 + 4096 × 4096 + 4096 × 10 ≈ 1.2 亿
```

卷积部分只有 900 多万。**全连接层是参数的绝对大头**。

### 3.2 用 1×1 卷积替代全连接

B15 的 4.3 节讲过：1×1 卷积等价于**在通道维上的全连接**。
所以可以用 1×1 卷积做"全连接"的工作，同时保留四维形状。

**NiN 块**：

```python
def nin_block(num_channels, kernel_size, strides, padding):
    """一个普通卷积（核大小可配）接两个 1×1 卷积，每个后接 ReLU。"""
```

前两个 1×1 卷积的作用：在通道维上做两次线性变换，参数极少
（`num_channels × num_channels`，比全连接的百万级小几个数量级）。

### 3.3 全局平均池化

NiN 的最后一步：

1. 用一个通道数等于类别数的 NiN 块，输出 `(N, num_classes, H, W)`
2. **全局平均池化**：对每个通道的全部空间位置求平均，得到 `(N, num_classes, 1, 1)`
3. 展平成 `(N, num_classes)`

```python
nn.AdaptiveAvgPool2d(1)      # 输出固定为 1×1，不管输入多大
```

**这一步取代了最后那个全连接层**：每个通道的平均值就是该类别的分数。

**好处**：参数几乎归零；输入图像尺寸可以变化。
**代价**：收敛更慢，书上说"有时会造成训练时间增加"。

### 3.4 NiN 的形状链（输入 1×224×224）

`nin_block` 的四个参数依次是 **输出通道数、核大小、步幅、填充（每一侧）**。

| 层 | 输出 |
|---|---|
| nin_block(96, 11, 4, 0) | `(N, 96, 54, 54)` |
| MaxPool 3×3，步幅 2 | `(N, 96, 26, 26)` |
| nin_block(256, 5, 1, 2) | `(N, 256, 26, 26)` |
| MaxPool 3×3，步幅 2 | `(N, 256, 12, 12)` |
| nin_block(384, 3, 1, 1) | `(N, 384, 12, 12)` |
| MaxPool 3×3，步幅 2 | `(N, 384, 5, 5)` |
| Dropout(0.5) | 形状不变 |
| nin_block(num_classes, 3, 1, 1) | `(N, 10, 5, 5)` |
| 全局平均池化 | `(N, 10, 1, 1)` |
| Flatten | `(N, 10)` |

## 4 GoogLeNet

### 4.1 Inception 块：四条路并行

Inception 块在同一层里**并行**跑四种运算，再把结果在通道维拼起来：

| 线路 | 组成 | 作用 |
|---|---|---|
| 1 | 1×1 卷积 | 提取单像素尺度 |
| 2 | 1×1 卷积 → 3×3 卷积 | 先降维，再提取 3×3 尺度 |
| 3 | 1×1 卷积 → 5×5 卷积 | 先降维，再提取 5×5 尺度 |
| 4 | 3×3 最大池化（填充 1、步幅 1）→ 1×1 卷积 | 保留原始信息再调通道 |

**四条线的输出高宽必须相同**，才能按通道拼接。所以：

- 1×1 卷积不需要填充
- 3×3 卷积填充 1
- 5×5 卷积填充 2
- 池化用 3×3、步幅 1、填充 1

**线路 2 与 3 前面那个 1×1 卷积是降维**。直接对输入做 5×5 卷积，参数量会很大；
先用 1×1 把通道降下来，再做 5×5，参数少很多。这个技巧叫 **bottleneck**。

### 4.2 拼接用 `torch.cat`

```python
torch.cat([p1, p2, p3, p4], dim=1)      # 在通道维拼接
```

**通道维是第 1 维**（第 0 维是批量）。拼完通道数等于四条线之和。

### 4.3 GoogLeNet 的整体结构

五个模块，每个之间用 3×3 步幅 2 的池化减半（填充 1）：

| 模块 | 内容 | 输出高宽 |
|---|---|---|
| b1 | 7×7 卷积（64，步幅 2，填充 3）+ 池化 | 224 → 56 |
| b2 | 1×1 卷积（64）+ 3×3 卷积（192，填充 1）+ 池化 | 56 → 28 |
| b3 | 2 个 Inception + 池化 | 28 → 14 |
| b4 | 5 个 Inception + 池化 | 14 → 7 |
| b5 | 2 个 Inception + 全局平均池化 | 7 → 1 |

最后接一个 `Linear(num_classes)`。**全部卷积、没有全连接**——与 NiN 的思路一致。

### 4.4 四个网络的参数对比（本机实测，输入 1 通道 224×224）

| 网络 | 总参数 | 全连接部分 |
|---|---|---|
| AlexNet | 46,764,746 | 三个大层，占绝大部分 |
| VGG-11 | 128,806,154 | 两个 4096 层，占绝大部分 |
| **NiN** | **1,992,166** | **零** |
| **GoogLeNet** | **5,977,530** | **零**（只有一个输出层 1024→10）|

**NiN 比 AlexNet 少 23 倍，比 VGG 少 64 倍。** 这说明加深加宽不一定要加参数——
把全连接换成全局平均池化、用 1×1 降维，参数量能降一个数量级以上。

**AlexNet 的 4678 万比论文里的 6000 万少**：论文是 3 通道输入，这里用 Fashion-MNIST
的单通道。第一层卷积少了 3 倍的参数（`96×3×11×11` 对 `96×1×11×11`），
差值约 900 万。

## 5 四条思路对比

| 网络 | 核心贡献 | 今天的地位 |
|---|---|---|
| AlexNet | ReLU + Dropout + 深网络训得动 | 每个现代网络的默认配置 |
| VGG | 用块搭网络 | 块的思想是后续所有网络的基础 |
| NiN | 1×1 卷积 + 全局平均池化 | 现代网络的标配 |
| GoogLeNet | 多尺度并行 + bottleneck | Inception 结构影响至今 |

**四个网络都用了 1×1 卷积**（NiN 与 GoogLeNet 是主角，AlexNet 没有，VGG 也没有）。
现代网络里 1×1 卷积几乎无处不在，用来调通道数。

## 6 实现会踩的坑

| 坑 | 症状 | 原因 |
|---|---|---|
| 形状链取整算错 | `mat1 and mat2 shapes cannot be multiplied` | 用 `⌊(n-k+2p)/s⌋+1`（1.3）|
| AlexNet 里漏了 `nn.ReLU()` | 模型能跑但效果差 | torch 的 `nn.Linear` 不含激活（1.2）|
| Inception 四条线高宽不一致 | `torch.cat` 报尺寸不匹配 | 填充数要按核大小算（4.1）|
| `torch.cat` 用 `dim=0` | 批量维被拼起来 | 通道维是 `dim=1`（4.2）|
| 全局池化用 `AvgPool2d` 固定窗口 | 输入尺寸一变就错 | 用 `AdaptiveAvgPool2d(1)`（3.3）|
| VGG 的 `conv_arch` 通道数与池化次数对不上 | 展平维度算错 | 块数决定高宽减半几次（2.2）|

| 命令 | 作用 | 讲义哪一节 |
|---|---|---|
| `nn.Dropout(p)` | 丢弃层 | 1.1 |
| `nn.AdaptiveAvgPool2d(1)` | 全局平均池化 | 3.3 |

| `nn.Conv2d(in, out, kernel_size, padding, stride)` | 卷积 | B15 的 2.1 |

## 自测题

1. AlexNet 相对 LeNet 改了哪四处？哪一处最关键？
2. 输入 224×224，卷积核 11、步幅 4、无填充，输出多大？再跟 3×3 步幅 2 的池化呢？
3. VGG 的 `conv_arch = ((1,64),(1,128),(2,256),(2,512),(2,512))` 表示什么？
   最终展平维度是多少？
4. NiN 用什么替代全连接层？为什么这样能大幅减少参数？
5. 全局平均池化怎么做？它为什么能取代最后的全连接层？
6. Inception 块里为什么线路 2 和 3 前面要加 1×1 卷积？
7. Inception 块的四条线怎么保证高宽一致？

## 答案（做完再看）

**1.** 更深（5 卷积 + 3 全连接）、ReLU 替代 sigmoid、Dropout 正则化、第一层 11×11 大步幅。
**最关键的是 ReLU**——B16 实测过，sigmoid 在这个规模上训练不动。

**2.** 卷积：`⌊(224-11)/4⌋+1 = 54`，即 54×54。池化：`⌊(54-3)/2⌋+1 = 26`，即 26×26。

**3.** 5 个 VGG 块，分别有 1、1、2、2、2 个 3×3 卷积，输出通道 64、128、256、512、512。
每块末尾池化减半，224 经过 5 次减半是 7。展平 `512 × 7 × 7 = 25088`。

**4.** 用 1×1 卷积。1×1 卷积等价于通道维上的全连接，参数只有 `c_in × c_out`，
比全连接层的 `c_in×H×W × c_out` 少掉 `H×W` 倍。最后再用全局平均池化取代输出层。

**5.** `nn.AdaptiveAvgPool2d(1)`：对每个通道的所有空间位置求平均，得到 `(N, C, 1, 1)`。
因为分类只需要每个类别一个分数，通道数等于类别数时，这个平均值就是分数——
不需要再乘一个大矩阵。

**6.** **降维（bottleneck）**。直接对输入做 5×5 卷积参数量很大；先用 1×1 把通道数降下来，
再做 5×5，参数少很多。

**7.** 靠填充：1×1 不填充、3×3 填 1、5×5 填 2、3×3 池化步幅 1 填 1。
每种运算都让输出与输入同高宽，四条线的结果才能按通道拼接。
