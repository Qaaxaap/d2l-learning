## 0 这一单元解决什么问题

B06 的线性回归与 B07 的 softmax 回归，模型部分都是 $\mathbf{X}\mathbf{W} + \mathbf{b}$：
输入经过一次线性变换就得到输出。这种模型的表达能力有上限——它能表示的决策边界
只能是直线或平面。

这一章解决这个问题。要回答三件事：

1. **加一层就能更强吗**：把两个线性变换串起来会怎样
2. **如果不够，缺的是什么**：激活函数的作用
3. **加了之后怎么训**：参数量、初始化、形状怎么变

## 1 隐藏层与"为什么不够"

### 1.1 结构

在输入与输出之间插入一层，叫**隐藏层**（hidden layer），其中的单元叫**隐藏单元**
（hidden unit）。输入与隐藏层之间、隐藏层与输出之间都是全连接。

设批量大小 $n$、输入个数 $d$、隐藏单元个数 $h$、输出个数 $q$。
隐藏层的输出记作 $\mathbf{H} \in \mathbb{R}^{n\times h}$：

$$\begin{aligned}
\mathbf{H} &= \mathbf{X}\mathbf{W}_h + \mathbf{b}_h,\\
\mathbf{O} &= \mathbf{H}\mathbf{W}_o + \mathbf{b}_o,
\end{aligned}$$

其中 $\mathbf{W}_h\in\mathbb{R}^{d\times h}$、$\mathbf{b}_h\in\mathbb{R}^{1\times h}$、
$\mathbf{W}_o\in\mathbb{R}^{h\times q}$、$\mathbf{b}_o\in\mathbb{R}^{1\times q}$。

**"层数"怎么数**：输入层不涉及计算，所以上面这个结构叫**两层**（隐藏层加输出层）。
书上 3.8 节明确说了这一点，读的时候别数错。

### 1.2 直接把两层串起来没有用

这是这一章最关键的一步。把上面两式联立：

$$\mathbf{O} = (\mathbf{X}\mathbf{W}_h + \mathbf{b}_h)\mathbf{W}_o + \mathbf{b}_o
= \mathbf{X}\underbrace{\mathbf{W}_h\mathbf{W}_o}_{\text{新的权重}} + \underbrace{\mathbf{b}_h\mathbf{W}_o + \mathbf{b}_o}_{\text{新的偏置}} .$$

结果仍然是一个线性变换：输出等于输入乘某个矩阵加某个向量。
**隐藏层白加了**——它与单层网络完全等价。再加更多层也一样，因为矩阵乘积还是矩阵。

**所以缺的不是层数，是打破线性的东西。**

## 2 激活函数

对隐藏层的输出再作用一个**逐元素的非线性函数** $\sigma$：

$$\mathbf{H} = \sigma(\mathbf{X}\mathbf{W}_h + \mathbf{b}_h) .$$

这时联立不再成立（$\sigma$ 不能吸收进矩阵乘法），模型的表达能力就超出了线性模型。

**"逐元素"很重要**：$\sigma$ 独立作用在每个元素上，不混合不同样本、不同单元的信息。
它在每个位置做同样的标量函数。

下面三个函数在书上 3.8 节都出现了。

### 2.1 ReLU

$$\operatorname{ReLU}(x) = \max(x, 0) .$$

导数分段：$x>0$ 时为 1，$x<0$ 时为 0，$x=0$ 处不可导（实际实现里取 0 或 1 都行）。

**为什么它是默认选择**：

- 计算便宜：只比较一次，没有指数运算
- 导数简单：要么 1 要么 0，不会因为链式法则连乘而衰减
- 一半的区间导数为 0，产生稀疏性

**书上实现它的方式**：3.9 节用 `maximum(X, 0)` 手写，而不是调现成的 `relu`。
理由是这一节要看清它到底做了什么——就一个取最大值。

**"死神经元"**：如果某个单元的输入长期为负，它的梯度恒为 0，权重再也不更新。
这是 ReLU 的已知问题，后面讲初始化与学习率时会再遇到。

### 2.2 sigmoid

$$\operatorname{sigmoid}(x) = \frac{1}{1+\exp(-x)} .$$

把任意实数压到 $(0,1)$，形状像 S。导数有一个漂亮的形式：

$$\operatorname{sigmoid}'(x) = \operatorname{sigmoid}(x)\left(1-\operatorname{sigmoid}(x)\right) .$$

**问题**：导数最大只有 0.25。多层反向传播时这些小数连乘，梯度会迅速趋近 0，
这就是**梯度消失**。所以现在很少把它用作隐藏层的激活函数。

它仍有用途：需要输出落在 $(0,1)$ 时（例如二分类的概率、门控机制）。

### 2.3 tanh

$$\tanh(x) = \frac{1-\exp(-2x)}{1+\exp(-2x)} .$$

把任意实数压到 $(-1,1)$，形状与 sigmoid 相同但**关于原点对称**。导数：

$$\tanh'(x) = 1-\tanh^2(x) .$$

导数最大为 1（在 $x=0$ 处），比 sigmoid 好一点，但两端仍然会饱和到 0，
所以深层网络里同样有梯度消失问题。

### 2.4 怎么选

| 函数 | 值域 | 导数最大值 | 现在的用法 |
|---|---|---|---|
| ReLU | $[0,\infty)$ | 1（正半轴） | 隐藏层的默认选择 |
| sigmoid | $(0,1)$ | 0.25 | 需要 $(0,1)$ 输出时 |
| tanh | $(-1,1)$ | 1 | 需要零中心且有界时 |

一句话：**隐藏层用 ReLU，除非有理由不用**。B09 之后会看到 sigmoid 与 tanh
在循环网络里还活着（那里需要把值压在界内）。

## 3 多层感知机

把上面两块合起来就是多层感知机（multilayer perceptron，MLP）：

$$\begin{aligned}
\mathbf{H} &= \operatorname{ReLU}(\mathbf{X}\mathbf{W}_h + \mathbf{b}_h),\\
\mathbf{O} &= \mathbf{H}\mathbf{W}_o + \mathbf{b}_o,\\
\hat{\mathbf{Y}} &= \operatorname{softmax}(\mathbf{O}).
\end{aligned}$$

最后一步与 B07 相同，训练用的还是交叉熵。

### 3.1 参数量

| 层 | 权重形状 | 参数个数 |
|---|---|---|
| 隐藏层 | $(784, 256)$ | 200704 |
| 隐藏层偏置 | $(256,)$ | 256 |
| 输出层 | $(256, 10)$ | 2560 |
| 输出层偏置 | $(10,)$ | 10 |
| 合计 | | **203530** |

对比 B07 的单层：$784\times10+10 = 7850$。加了隐藏层之后参数量涨了 25 倍左右。

**这带来两件事**：模型能表示的东西多了；过拟合的风险也跟着上来。
B09 会专门讲这件事（模型选择、权重衰减、丢弃法）。

### 3.2 层数与宽度

隐藏单元个数 $h$ 是**超参数**。书上取 256。

并不是越宽越好，也不是越深越好：宽度与深度增加的是表达能力，同时增加的是
参数与训练难度。B09 与 B13 会分别讲这两件事。

### 3.3 万能近似定理

书上没写，这里只给结论：足够宽的单隐藏层网络可以以任意精度逼近任意连续函数。
这个结论说明了"为什么加非线性就够强"，但它**不保证**用梯度下降能找到那组参数，
也不说明需要多少隐藏单元。所以它是个理论保证，不是实用指南。

## 4 从零实现

这一节的代码与 B07 高度重复：**数据、损失、训练循环、评估全都不变，只换模型**。
重复的部分不再解释，对照 B07 的 5.1 到 5.5 节即可。

### 4.1 需要导入什么

```python
import torch
import torch.nn as nn
from torch.utils.data import DataLoader
from torchvision import datasets, transforms
```

与 B07 相同。从零实现这一节只用 `torch`。

### 4.2 参数

超参数：`num_inputs = 784`、`num_hiddens = 256`、`num_outputs = 10`。

四个参数：

| 名字 | 形状 | 初始化 |
|---|---|---|
| `W1` | $(784, 256)$ | 均值 0、标准差 0.01 的正态随机数 |
| `b1` | $(256,)$ | 全零 |
| `W2` | $(256, 10)$ | 同上 |
| `b2` | $(10,)$ | 全零 |

与 B07 一样，四个都要开 `requires_grad`。

**形状怎么记**：每一层的权重形状是"输入个数 × 输出个数"。`W1` 把 784 维变成 256 维，
`W2` 把 256 维变成 10 维。**相邻两个矩阵的内维必须对上**（$784\to256$ 接 $256\to10$），
对不上就是 B07 里那个 `mat1 and mat2 shapes cannot be multiplied` 报错。

### 4.3 激活函数

`relu(X)` 返回 `X` 与 0 逐元素的最大值。

**书上自己写而不调现成的**，因为这一节要看清楚激活函数做了什么。torch 里有
`torch.relu` 与 `nn.ReLU`，到第 5 节才用。

### 4.4 模型

`net(X)` 做三件事：把图像拉平成 $(n, 784)$、算隐藏层并过激活函数、算输出层。
返回的是 **logits**，不是概率——softmax 由损失函数内部处理（B07 的 6.2 节）。

### 4.5 训练

与 B07 完全相同：小批量、交叉熵、`sgd` 更新。

**超参数与实测**：第二版用的是 10 轮、学习率 0.1、批量 256。
本机实测（全量 6 万训练样本、10 轮）测试精度稳定在 0.85 左右，训练耗时约 12 秒。

**小数据集上不要用同一套超参数**：把训练集缩到 1 万时，同样的设置会让精度在
0.65 到 0.81 之间大幅跳动。参数量 20 万而样本只有 1 万，模型容量远超数据量，
训练不稳是正常现象。这一章的题目与断言都用全量数据。

这也解释了为什么 B07 的断言用 1 万样本而这一章要用全量：
线性模型的参数量小得多，小数据集上就够稳。

### 4.6 两版书在这两处写法不同

读纸质书与电子版时会遇到两个对不上的地方，都不是错，是框架约定不同：

| | 纸质书（Gluon） | 电子版（PyTorch） |
|---|---|---|
| 激活函数 | 写在层的参数里：`nn.Dense(256, activation='relu')` | 独立的子层：`nn.ReLU()` |
| 输入维 | 靠延后初始化推断，不必写 | `nn.Linear(784, 256)` 必须写出 784 |
| 拉平 | 不需要，`nn.Dense` 自动在最后一维做仿射 | 需要 `nn.Flatten()` |

第三行是最容易漏的：两版的数据都是 $(256,1,28,28)$，Gluon 的 `nn.Dense` 会自己处理，
而 `nn.Linear` 只把最后一维当特征维。所以 torch 这边**必须**显式拉平。

## 5 简洁实现

模型的三个部件各自对应一个模块：

| 自己写的 | 框架里的 |
|---|---|
| 拉平图像 | `nn.Flatten()` |
| `relu(X @ W1 + b1)` | `nn.Linear(784, 256)` 加 `nn.ReLU()` |
| `X @ W2 + b2` | `nn.Linear(256, 10)` |

串起来：

```python
net = nn.Sequential(
    nn.Flatten(),
    nn.Linear(784, 256),
    nn.ReLU(),
    nn.Linear(256, 10),
)
```

`nn.Flatten()` 把除第一维以外的所有维度拉平，$(n,1,28,28)\to(n,784)$。
有了它，从零实现里那句 `X.reshape(X.shape[0], -1)` 在简洁实现里不必再写。

**注意 `nn.Flatten()` 的位置**：它放在最前面，因为它处理的是输入。
若写在 `nn.Linear` 之后，语义就完全变了。

其余部分（损失、优化器、训练循环）与 B07 的简洁实现逐字相同。

## 6 实现会踩的坑

| 坑 | 症状 | 原因 |
|---|---|---|
| 忘了激活函数 | 不报错，精度与单层线性模型一样 | 两个线性层等价于一个（1.2） |
| 激活函数放在输出层 | 精度下降 | 输出层要出 logits，softmax 由损失函数做（4.4） |
| 把 softmax 塞进 `net` | 不报错，收敛变慢 | `CrossEntropyLoss` 内含 softmax（B07 的 6.2） |
| `W1` 与 `W2` 的内维对不上 | `shapes cannot be multiplied` | 每一层的输出个数要等于下一层的输入个数（4.2） |
| 忘了 `nn.Flatten()` | 同样的形状报错 | 线性层要 $(n,784)$，图像是 $(n,1,28,28)$（5） |
| 隐藏单元数取 1 | 不报错，退化成线性模型 | 宽度为 1 时非线性被压掉 |
| 用 sigmoid 做隐藏层激活 | 训练慢、精度低 | 导数最大 0.25，多层连乘后梯度消失（2.2） |
| 参数量大导致过拟合 | 训练精度高、测试精度低 | 20 万参数对 6 万样本，B09 讲对策（3.1） |

## 答案（做完再看）

**1.** $\mathbf{O}=(\mathbf{X}\mathbf{W}_h+\mathbf{b}_h)\mathbf{W}_o+\mathbf{b}_o
=\mathbf{X}(\mathbf{W}_h\mathbf{W}_o)+(\mathbf{b}_h\mathbf{W}_o+\mathbf{b}_o)$。
两个矩阵相乘还是矩阵，所以整体仍是 $\mathbf{X}$ 的线性函数。

**2.** 如果函数会混合不同单元或不同样本的信息，那它本身就是一个横向的运算，
联立时能被吸收进矩阵乘法，起不到打破线性的作用。逐元素作用才保证"每个位置独立变换"。

**3.** ReLU：值域 $[0,\infty)$，正半轴导数为 1。sigmoid：值域 $(0,1)$，导数最大 0.25。
tanh：值域 $(-1,1)$，导数最大 1（在 0 处）。

**4.** ReLU。sigmoid 与 tanh 的导数在两端饱和到 0，多层反向传播会梯度消失；
ReLU 在正半轴导数恒为 1，不会衰减。

**5.** 为了让读者看清激活函数是什么——就是一个取最大值的逐元素运算，
没有别的机关。用现成的封装会把它变成一个名字，看不出内容。

**6.** 隐藏层 $784\times256+256=200960$，输出层 $256\times10+10=2570$，合计 203530。
B07 的单层是 $784\times10+10=7850$，涨了约 26 倍。

**7.** 它处理的是输入形状：把 $(n,1,28,28)$ 拉成 $(n,784)$，后面的线性层才能接。
放在中间或末尾处理的就变成中间层的输出了，语义完全不同。

**8.** 精度与 B07 的线性模型几乎一样。两个线性层等价于一个，
所以模型的实际容量没有增加。
