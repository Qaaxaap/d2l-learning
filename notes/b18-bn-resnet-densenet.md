# B18 批量归一化、残差与稠密连接

三个改进，各解决一个具体问题：

| 技术 | 解决什么 |
|---|---|
| **批量归一化（BN）** | 深层网络里中间层分布不断漂移，训练不稳定 |
| **残差连接（ResNet）** | 网络加深到一定程度后，训练误差反而变大 |
| **稠密连接（DenseNet）** | 每一层的输入只用上一层的输出，信息传递太单薄 |

## 1 批量归一化

### 1.1 解决什么问题

训练深层网络时，前面层的参数一变，后面层收到的输入分布就跟着变。
后层要不断适应新分布，训练变得难收敛。

**批量归一化（Batch Normalization）**的做法：在每个小批量上，把某一层的输出
**强行拉回均值 0、方差 1**，再乘一个可学习的缩放与偏移。

### 1.2 训练时的四步

对一个由 $m$ 个样本组成的小批量，某个特征维（或通道）上的值 $\{x^{(1)}, \ldots, x^{(m)}\}$：

**第一步，算均值**：

$$\mu = \frac{1}{m}\sum_{i=1}^{m} x^{(i)}$$

**第二步，算方差**：

$$\sigma^2 = \frac{1}{m}\sum_{i=1}^{m}(x^{(i)} - \mu)^2$$

**第三步，标准化**：

$$\hat{x}^{(i)} = \frac{x^{(i)} - \mu}{\sqrt{\sigma^2 + \epsilon}}$$

$\epsilon$ 是一个很小的常数（默认 `1e-5`），防止分母为 0。

**第四步，缩放与偏移**：

$$y^{(i)} = \gamma \odot \hat{x}^{(i)} + \beta$$

$\gamma$ 与 $\beta$ 是**可学习的参数**，形状与特征维相同。

**为什么要加 $\gamma$ 和 $\beta$**：标准化之后分布固定在均值 0、方差 1，
这可能限制了表达能力。$\gamma$ 与 $\beta$ 允许网络**学回来**——如果 BN 没用，
理论上能学出 $\gamma = \sqrt{\sigma^2 + \epsilon}$、$\beta = \mu$，把 BN 变回恒等映射。

### 1.3 全连接层与卷积层的差别

| 层类型 | 输入形状 | 在哪个维度上算均值方差 | $\gamma$、$\beta$ 的形状 |
|---|---|---|---|
| **全连接** | `(N, features)` | 第 0 维（批量） | `(features,)` |
| **卷积** | `(N, C, H, W)` | 第 0、2、3 维（批量 + 高 + 宽）| `(C,)` |

**卷积的 BN 是"每个通道一套统计量"**：把 `N × H × W` 个元素放在一起算一个均值一个方差。
所以 `nn.BatchNorm2d(C)` 的参数是长度为 `C` 的向量。

**实现上的关键点**：卷积的情况要 `keepdim=True`，否则算出来的均值是 `(C,)`，
减不回去——广播时维度对不上。

### 1.4 预测时怎么办

训练时用**当前小批量**的均值方差；预测时只有一个样本（或者一批没有统计意义的样本），
不能再依赖批内统计。

**做法**：训练过程中维护一份**移动平均**：

```
moving_mean = momentum * moving_mean + (1 - momentum) * batch_mean
moving_var  = momentum * moving_var  + (1 - momentum) * batch_var
```

预测时直接用 `moving_mean` 与 `moving_var` 做标准化（不再乘 $\gamma$、$\beta$ 之外的变换）。

**`momentum` 的默认值是 0.1**，指的是"旧值保留多少"。torch 的 `nn.BatchNorm2d(momentum=0.1)`
就是上面这个公式。

**这意味着 BN 在训练与预测两种模式下计算结果不同**——和 Dropout 一样，
所以 `net.train()` 与 `net.eval()` 对 BN 有实际影响。

### 1.5 从零实现的要点

函数签名（不用自己写，题目里会给）：

```python
def batch_norm(X, gamma, beta, moving_mean, moving_var, eps, momentum, training):
    """返回 (Y, 更新后的 moving_mean, 更新后的 moving_var)"""
```

**训练模式**：

1. 判断 `X.dim()` 是 2 还是 4
2. 二维：`mean = X.mean(dim=0)`、`var = ((X - mean) ** 2).mean(dim=0)`
3. 四维：`mean = X.mean(dim=(0, 2, 3), keepdim=True)`、方差同理
4. 标准化：`X_hat = (X - mean) / torch.sqrt(var + eps)`
5. 更新移动平均
6. `Y = gamma * X_hat + beta`

**预测模式**：跳过 1 到 5，直接用 `moving_mean`、`moving_var` 标准化。

**`gamma` 与 `beta` 必须是 `nn.Parameter`**（B14 讲过），否则优化器看不到它们。

**`moving_mean` 与 `moving_var` 用 `register_buffer`**（B13 的 2.3 节）：
不训练、但要进 `state_dict`。这样保存模型时它们会一起被存下来。

### 1.6 用 `nn.BatchNorm2d`

实际写模型时用现成的：

```python
nn.BatchNorm2d(num_features)      # 四维输入，按通道归一化
nn.BatchNorm1d(num_features)      # 二维或三维输入
```

**位置**：卷积（或线性）之后、激活之前。顺序是 `Conv → BN → ReLU`。

## 2 残差网络 ResNet

### 2.1 退化问题

按直觉，网络越深表达能力越强，训练误差应该越低。实际不是：
**网络深到一定程度，训练误差反而变大**。

这不是过拟合（过拟合是训练误差低、测试误差高），而是**优化困难**——
更深的网络更难训到好的解。

书的说法：如果理想映射接近恒等映射，那么"学一个残差映射"比"直接学原映射"容易。

### 2.2 残差块

**普通块**要学 $f(x)$；**残差块**要学 $f(x) - x$，输出是

$$\text{ReLU}(f(x) + x)$$

那条把 $x$ 直接加到输出上的路径叫**跳跃连接**（skip connection）。

**结构**：

```
输入 x
  ├── Conv 3×3 → BN → ReLU → Conv 3×3 → BN ──┐
  │                                           加 ──→ ReLU ──→ 输出
  └───────────────────────────────────────────┘
```

**要求**：两个卷积的输出形状必须与输入相同，才能相加。

**改变通道数或尺寸时**：输入要经过一个 1×1 卷积（步幅与卷积相同）变换成目标形状，
再加。

**形状规则**：

| 情况 | 主干 | 跳跃路径 |
|---|---|---|
| `strides=1`、通道不变 | 保持形状 | 直接加 |
| `strides=2`、通道变化 | 高宽减半、通道变 | 1×1 卷积（步幅 2）|

### 2.3 ResNet-18 的整体结构

| 部分 | 内容 | 输出高宽 |
|---|---|---|
| 前置 | 7×7 卷积（64，步幅 2，填充 3）+ BN + ReLU + 3×3 池化（步幅 2，填充 1）| 224 → 56 |
| stage 1 | 2 个残差块（64 通道）| 56 |
| stage 2 | 2 个残差块（128，第一个步幅 2）| 28 |
| stage 3 | 2 个残差块（256，第一个步幅 2）| 14 |
| stage 4 | 2 个残差块（512，第一个步幅 2）| 7 |
| 尾部 | 全局平均池化 → 全连接 10 | 1 |

**每个 stage 的第一个块用 1×1 卷积调整跳跃路径**，其余块直接相加。

## 3 稠密连接 DenseNet

### 3.1 稠密块

ResNet 是"加"（`Y + X`），DenseNet 是"拼"（`cat([X, Y], dim=1)`）。

**稠密块的每个子块做**：

```
BN → ReLU → Conv 3×3（输出 num_channels 个通道）
```

然后把**输入与输出在通道维拼接**：

```
X = cat([X, Y], dim=1)
```

**通道增长**：输入 3 通道、2 个子块、每个 10 通道，输出是 `3 + 2×10 = 23` 通道。

**这个 `num_channels` 叫增长率（growth rate）**。它控制每层新增多少通道。

### 3.2 过渡层

稠密块会让通道数不断增长，需要控制。**过渡层**：

```
BN → ReLU → 1×1 卷积（把通道数减半）→ 平均池化 2×2 步幅 2（高宽减半）
```

### 3.3 DenseNet 的整体结构

| 部分 | 内容 |
|---|---|
| 前置 | 7×7 卷积（64，步幅 2，填充 3）+ BN + ReLU + 3×3 池化（步幅 2，填充 1）|
| 稠密块 1 | 4 个子块，增长率 32 → 通道 64 + 4×32 = 192 |
| 过渡层 1 | 通道减半到 96，高宽减半 |
| 稠密块 2 | 4 个子块 → 96 + 4×32 = 224 |
| 过渡层 2 | 减半到 112，高宽减半 |
| 稠密块 3 | 4 个子块 → 112 + 4×32 = 240 |
| 过渡层 3 | 减半到 120，高宽减半 |
| 稠密块 4 | 4 个子块 → 120 + 4×32 = 248 |
| 尾部 | BN → ReLU → 全局平均池化 → 全连接 10 |

### 3.4 ResNet 与 DenseNet 的对比

| 项目 | ResNet | DenseNet |
|---|---|---|
| 连接方式 | 相加 `Y + X` | 拼接 `cat([X, Y])` |
| 通道数 | 每块固定 | 每块增长 `growth_rate` |
| 参数效率 | 高 | 更高（每层只学新增的通道）|
| 显存占用 | 较低 | 较高（要保存所有中间输出）|

## 4 实现会踩的坑

| 坑 | 症状 | 原因 |
|---|---|---|
| 卷积 BN 忘了 `keepdim=True` | 减均值时报形状错误 | 算出的均值是 `(C,)`，无法从 `(N,C,H,W)` 减（1.3）|
| `gamma`/`beta` 没包 `nn.Parameter` | 不报错，但训练里不更新 | B14 讲过（1.5）|
| moving stats 没 `register_buffer` | 保存的模型里没有它们 | B13 的 2.3（1.5）|
| 预测时忘了用 `eval()` | 预测结果依赖同一批里的其他样本 | BN 两种模式不同（1.4）|
| 残差块输入输出形状不等 | 相加时报形状错误 | 改通道/尺寸时要用 1×1 卷积（2.2）|
| `cat` 用了 `dim=0` | 批量维被拼起来 | 通道维是 `dim=1`（3.1）|
| BN 的 `momentum` 理解反了 | 移动平均更新太快或太慢 | 它指"旧值保留多少"（1.4）|

3. 预测时 BN 用什么统计量？`momentum` 的含义是什么？
4. 残差块解决什么问题？改通道数时跳跃路径要做什么？
5. DenseNet 的稠密块怎么连接？通道数怎么变？
6. 过渡层由哪些层组成？起什么作用？
7. `net.eval()` 对 BN 有什么影响？忘了调会怎样？

## 答案（做完再看）

**1.** 算小批量的均值、算方差、标准化成均值 0 方差 1、乘 $\gamma$ 加 $\beta$。
$\gamma$ 与 $\beta$ 是可学习的缩放与偏移，允许网络在 BN 无益时把它学回恒等映射。

**2.** 全连接在第 0 维（批量）；卷积在第 0、2、3 维（批量 + 高 + 宽），即每个通道一套。
卷积要 `keepdim=True` 是因为算出来的是 `(C,)`，而输入是 `(N,C,H,W)`，
不保留维度就没法广播相减。

**3.** 用训练期间累积的移动平均 `moving_mean` 与 `moving_var`。
`momentum` 指旧值保留的比例（默认 0.1），
`moving_mean = momentum * 旧值 + (1-momentum) * 当前批均值`。

**4.** 解决退化问题——网络加深后训练误差反而变大。学残差 $f(x) - x$ 比直接学 $f(x)$ 容易。
改通道数或尺寸时，跳跃路径要先过一个 1×1 卷积（步幅一致）变换形状。

**5.** 每个子块输出 `growth_rate` 个通道，然后把输入与输出在通道维拼接。
所以通道数每经过一个子块增加 `growth_rate`。

**6.** `BN → ReLU → 1×1 卷积（通道减半）→ 平均池化 2×2 步幅 2（高宽减半）`。
作用是控制稠密块带来的通道膨胀。

**7.** `eval()` 让 BN 用移动平均的统计量而不是当前批的统计量。
忘了调的话，预测结果会依赖同一批里的其他样本，同一个输入换一批邻居得到不同输出。
