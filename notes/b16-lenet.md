## 0 这一单元解决什么问题

B08 的多层感知机把 28×28 的图像**逐行展开成 784 维向量**再喂给全连接层。这有两个问题：

1. **空间关系被打散**。同一列相邻的像素，在展开后的向量里相隔 28 个位置。
   模型要花很大力气才能学到"这两个像素是邻居"
2. **参数量随图像尺寸平方增长**。1000×1000 的彩色图，光是第一层
   就是 `3000000 × 256` 的权重，约 3 GB

卷积解决这两件事：核在图像上滑动，**保留空间结构**；同一个核在所有位置复用，
**参数量与图像尺寸无关**。

LeNet 是 1998 年 LeCun 用来识别手写数字的网络。它把"卷积 + 池化"叠两层，
再接三个全连接层。**这个结构今天还在用**，只是层更多、更深。

## 1 LeNet 的结构

### 1.1 两个块

LeNet 分成两半：

| 块 | 组成 | 作用 |
|---|---|---|
| **卷积块** | 卷积 → 池化 → 卷积 → 池化 | 提取特征，同时缩小空间尺寸 |
| **全连接块** | 展平 → 120 → 84 → 10 | 把特征映射成类别分数 |

**卷积块**的两个卷积层都用 5×5 的核：

- 第一层：输入 1 通道 → 输出 6 通道
- 第二层：输入 6 通道 → 输出 16 通道

两个池化层都是 2×2、步幅 2，让高宽各减半。

**全连接块**要先展平：卷积块输出 `(批量, 16, H, W)`，全连接层要 `(批量, 特征数)`。

### 1.2 为什么通道数在增加

1 → 6 → 16。**空间尺寸在缩小，通道数在增加**，两者相反。

原因是参数量：第一层卷积的参数是 `6 × 1 × 5 × 5 = 150`；
如果第二层保持 6 通道，参数是 `6 × 6 × 5 × 5 = 900`；
加到 16 通道是 `16 × 6 × 5 × 5 = 2400`。

**空间变小意味着每个通道能承载的信息更少**，所以用更多通道来补偿。
书上写的是"第二个卷积层比第一个的输入高宽要小，所以增加输出通道使两个卷积层的参数尺寸类似"。

## 2 形状变化表

### 2.1 第一版的形状（无填充）

| 层 | 输出形状 | 说明 |
|---|---|---|
| 输入 | `(N, 1, 28, 28)` | 单通道灰度图 |
| Conv 5×5, 6 通道 | `(N, 6, 24, 24)` | `28 - 5 + 1 = 24` |
| MaxPool 2×2, 步幅 2 | `(N, 6, 12, 12)` | 减半 |
| Conv 5×5, 16 通道 | `(N, 16, 8, 8)` | `12 - 5 + 1 = 8` |
| MaxPool 2×2, 步幅 2 | `(N, 16, 4, 4)` | 减半 |
| Flatten | `(N, 256)` | `16 × 4 × 4 = 256` |
| Linear 120 | `(N, 120)` | |
| Linear 84 | `(N, 84)` | |
| Linear 10 | `(N, 10)` | 10 个类别 |

### 2.2 第二版的形状（第一层加填充 2）

第二版给第一个卷积层加了 `padding=2`，整条链的形状不同：

| 层 | 输出形状 | 说明 |
|---|---|---|
| 输入 | `(N, 1, 28, 28)` | |
| Conv 5×5, 6 通道, **填充 2** | `(N, 6, 28, 28)` | 填充抵消了缩小 |
| AvgPool 2×2, 步幅 2 | `(N, 6, 14, 14)` | |
| Conv 5×5, 16 通道 | `(N, 16, 10, 10)` | `14 - 5 + 1 = 10` |
| AvgPool 2×2, 步幅 2 | `(N, 16, 5, 5)` | |
| Flatten | `(N, 400)` | `16 × 5 × 5 = 400` |
| Linear 120 | `(N, 120)` | |
| … | | |

**这两张表要对上代码里的数字**。第一版展平后是 256，第二版是 400。
写 `nn.Linear(?, 120)` 里的第一个数字时，**必须自己按上面的链算一遍**，
抄错一位就报形状不匹配。

## 3 两版差异

| 项目 | 第一版 | 第二版 |
|---|---|---|
| 第一个卷积层的填充 | 无 | `padding=2` |
| 池化类型 | **最大池化** | **平均池化** |
| 展平后的长度 | 256 | 400 |
| 展平的方式 | 全连接层自动展平 | 显式写 `nn.Flatten()` |

**池化类型为什么不同**：书上说，LeNet 原文用的是平均池化；
`ReLU` 与最大池化在当时还没出现。两版都保留了原始设计，所以一个是 MaxPool、
一个是 AvgPool。

**今天写代码用哪个**：**用最大池化、ReLU**。它们在多数任务上效果更好。
保留 LeNet 原始结构是为了对照历史，不是因为它最优。

### 3.1 展平：`nn.Flatten()`

卷积块输出 4 维 `(N, C, H, W)`，全连接层要 2 维 `(N, 特征数)`。

**`nn.Flatten()`** 做这件事：从第 1 维开始把所有维度拉平。
输入 `(N, 16, 5, 5)` 变成 `(N, 400)`。

```python
nn.Flatten()               # 默认从第 1 维开始，保留批量维
```

**第一版的 MXNet `Dense` 会自动展平**，torch 的 `nn.Linear` 不会——所以要显式写
`nn.Flatten()`，或者在前向里 `x.view(x.size(0), -1)`。

**`view` 的写法**：`x.view(x.size(0), -1)` 保留第 0 维（批量），其余全部拉平。
`x.view(-1, 16 * 5 * 5)` 也等价，但把 16×5×5 写死在代码里，改了输入尺寸就要改这里。

## 4 训练

### 4.1 数据

Fashion-MNIST：6 万张 28×28 灰度图，10 个类别（T恤、裤子、套头衫等）。
比手写数字难，但比 CIFAR-10 简单，适合第一个卷积网络。

```python
from torchvision import datasets, transforms
from torch.utils.data import DataLoader

transform = transforms.ToTensor()
train_set = datasets.FashionMNIST(root="data", train=True,
                                  transform=transform, download=True)
test_set = datasets.FashionMNIST(root="data", train=False,
                                 transform=transform, download=True)
train_iter = DataLoader(train_set, batch_size=256, shuffle=True)
test_iter = DataLoader(test_set, batch_size=256, shuffle=False)
```

**`transforms.ToTensor()`** 把 PIL 图像变成 `(1, 28, 28)` 的 float 张量，
并把像素值从 `[0, 255]` 缩放到 `[0, 1]`。**这一步不能省**——不缩放的话输入是 0 到 255，
梯度会爆炸。

### 4.2 设备

```python
device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
net.to(device)
```

**每一批数据也要搬到 device**，否则报
`Expected all tensors to be on the same device`（B14 的 3.4 节）。

### 4.3 训练循环

结构与 B12 的相同，四步：清梯度 → 前向 → 算损失 → 反向 + 更新。

```python
optimizer = torch.optim.SGD(net.parameters(), lr=0.1)
loss_fn = nn.CrossEntropyLoss()

for epoch in range(num_epochs):
    net.train()
    for X, y in train_iter:
        X, y = X.to(device), y.to(device)
        optimizer.zero_grad()
        loss = loss_fn(net(X), y)
        loss.backward()
        optimizer.step()
```

**两个模式**：

| 方法 | 什么时候调 | 影响什么 |
|---|---|---|
| `net.train()` | 每个 epoch 开始 | 让 Dropout 生效、BN 用批统计量 |
| `net.eval()` | 评估之前 | 让 Dropout 关掉、BN 用运行统计量 |

这一章的 LeNet 没有 Dropout 与 BN，两个模式没有区别。**但要从一开始就养成写的习惯**——
B18 的 BN 与 B19 起会立刻需要它。

**评估时包 `torch.no_grad()`**：不建计算图，省显存也更快。

### 4.4 精度与速度（本机实测）

**激活函数用 ReLU、池化用最大池化**时（本机 RTX 4070 SUPER，批 256，lr 0.1）：

| 训练轮数 | 测试精度 |
|---|---|
| 5 | 0.82 |
| 10 | 0.86 |
| 12 | 0.86 |

速度约 **50000 examples/sec**，5 个 epoch 不到 6 秒。

**书上写的 0.87 到 0.90 在这个环境复现不出来**，而且原因不在超参：下面这一节说明。

### 4.5 实测：sigmoid 版本训练不动

把激活换成 sigmoid、其余不动，跑 5 个 epoch，测试精度**恒为 0.10**（等于在 10 个类里乱猜）。
训练损失从第一个 epoch 到最后都停在 2.30 附近，而 `log(10) = 2.303` 就是瞎猜的损失。

换学习率也没用：

| 配置 | 5 epoch 后的测试精度 |
|---|---|
| ReLU + MaxPool | 0.82 |
| sigmoid + MaxPool，lr = 0.1 | 0.10 |
| sigmoid + MaxPool，lr = 0.5 | 0.10 |
| sigmoid + MaxPool，lr = 0.01 | 0.10 |

**换成第二版的原版结构**（第一层加填充 2、用平均池化）也一样难训：
lr 0.9 时前 5 个 epoch 不动、第 10 个 epoch 才到 0.62；lr 0.1 时 10 个 epoch 完全不动。

**为什么**：sigmoid 的导数最大只有 0.25，堆两层卷积加三层全连接的链上，
梯度每传一层就乘一个小于 1 的因子——B11 讲的梯度消失。参数几乎不动，
损失停在瞎猜的水平。ReLU 在正半轴导数恒为 1，没有这个问题。

**结论**：写卷积网络用 ReLU。书上保留 sigmoid 是为了还原 1998 年的原始设计，
不是因为它能用。

### 4.6 examples/sec

书上打印 **examples/sec**（每秒处理的样本数）：

```
examples/sec = 总样本数 × epoch 数 / 总耗时
```

换设备、换模型、换批大小时这个数字都会变，是判断训练速度的基准。本机约 5 万。

## 5 实现会踩的坑

| 坑 | 症状 | 原因 |
|---|---|---|
| `nn.Linear` 的第一个数字算错 | `mat1 and mat2 shapes cannot be multiplied` | 必须按形状链算到展平的那一步（2.1、2.2）|
| 忘了 `nn.Flatten()` | 同上 | 4 维输入不能进 `nn.Linear`（3.1）|
| 忘了 `ToTensor()` | loss 是 `nan` | 输入是 0 到 255 而不是 0 到 1（4.1）|
| 模型在 GPU、数据在 CPU | `Expected all tensors to be on the same device` | 每批都要 `.to(device)`（4.2）|
| 忘了 `optimizer.zero_grad()` | 损失不降，梯度累加 | B12 讲过（4.3）|
| 评估时没包 `no_grad` | 显存一直涨 | 计算图被保留（4.3）|
| 用 sigmoid 而不是 ReLU | 训练慢、精度低 | sigmoid 有梯度消失（B11）|

## 自测题

1. LeNet 的卷积块和全连接块各含几层？分别做什么？
2. 输入 28×28、不做填充、卷积核 5×5，第一层卷积输出多大？再做 2×2 步幅 2 的池化呢？
3. 第一版展平后是 256，第二版是 400。这个差从哪来？
4. LeNet 为什么把通道数从 1 增到 6 再增到 16？
5. 卷积块输出的 4 维张量怎么才能进 `nn.Linear`？
6. `net.train()` 与 `net.eval()` 影响哪些层？这一章的 LeNet 有没有区别？
7. 为什么数据要用 `transforms.ToTensor()`？不用会怎样？
8. 本机实测 sigmoid 版本训练 5 个 epoch 精度恒为 0.10。原因是什么？

## 答案（做完再看）

**1.** 卷积块 4 层：卷积 → 池化 → 卷积 → 池化。全连接块 3 层：120、84、10，
前置一个展平。

**2.** 卷积后 `28-5+1 = 24`，即 24×24；池化 2×2 步幅 2 后 `24/2 = 12`，即 12×12。

**3.** 第二版给第一个卷积层加了 `padding=2`，28×28 经过它仍是 28×28（第一版是 24×24）。
后面每层都跟着变大，展平前是 16×5×5（第一版是 16×4×4），所以 400 对 256。

**4.** 空间尺寸在缩小，每个通道能承载的信息变少；增加通道数来补偿。
书上还说这样能让两层卷积的参数量相近。

**5.** 用 `nn.Flatten()`（或 `x.view(x.size(0), -1)`）把 `(N, C, H, W)` 变成 `(N, C*H*W)`。

**6.** 影响 Dropout（训练时随机丢，评估时不丢）与 BatchNorm（训练用批统计量，
评估用运行统计量）。这一章的 LeNet 两者都没有，所以两个模式没有实际区别，
但代码里该写。

**7.** `ToTensor()` 把像素从 0 到 255 缩放到 0 到 1。不缩放的话输入量级太大，
第一个线性层或卷积层的输出会非常大，梯度爆炸，损失变成 `nan`。

**8.** 梯度消失。sigmoid 的导数最大只有 0.25，梯度穿过五层时每层乘一个小于 1 的因子，
到前面的卷积层已经接近 0，参数几乎不动。损失停在 `log(10) ≈ 2.303`，等于瞎猜。
ReLU 正半轴导数为 1，不存在这个问题。
