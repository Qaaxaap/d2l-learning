## 0 这一单元解决什么问题

图像是二维的：`(高, 宽)`。把它拉平成一维向量交给全连接层会丢掉两件事：

1. **空间结构**：像素 `(i, j)` 与 `(i, j+1)` 的相邻关系
2. **平移不变性**：一只猫出现在图像的左上角还是右下角，都应该被认出来

**卷积**解决这两件事：它用一个**小窗口**（卷积核）在图像上滑动，每个位置都做同样的运算。
窗口小 → 只关心局部；同一个核到处滑动 → 参数共享，平移不变。

**代价**是输出会变小（窗口滑不到边缘外），所以引入**填充**。**池化**是另一个降尺寸的手段。

## 1 二维互相关

### 1.1 运算本身

给一个输入数组与一个**核**（kernel，也叫滤波器）：

```
输入 X (3×3):        核 K (2×2):
0 1 2                0 1
3 4 5                2 3
6 7 8
```

把核当作窗口，从左上角开始，**核与窗口覆盖的那一块按元素相乘再求和**：

```
0×0 + 1×1 + 3×2 + 4×3 = 19
```

窗口向右滑一格，再做一次：

```
1×0 + 2×1 + 4×2 + 5×3 = 25
```

**窗口滑动顺序**：从左到右，一行做完再下一行。

对这个例子的完整输出：

$$\begin{aligned}
19 &= 0{\times}0 + 1{\times}1 + 3{\times}2 + 4{\times}3\\
25 &= 1{\times}0 + 2{\times}1 + 4{\times}2 + 5{\times}3\\
37 &= 3{\times}0 + 4{\times}1 + 6{\times}2 + 7{\times}3\\
43 &= 4{\times}0 + 5{\times}1 + 7{\times}2 + 8{\times}3
\end{aligned}$$

**输出形状**：输入 $n_h\times n_w$、核 $k_h\times k_w$ 时，

$$(n_h - k_h + 1)\times(n_w - k_w + 1).$$

3×3 的输入配 2×2 的核，输出 2×2。

### 1.2 为什么叫"互相关"

**真正的卷积**要先把核**左右翻转、上下翻转**，再做同样的滑窗运算。

对上面的核 `[[0,1],[2,3]]`，翻转后是 `[[3,2],[1,0]]`，用它算出来的第一个元素是

$$0{\times}3 + 1{\times}2 + 3{\times}1 + 4{\times}0 = 5 \ne 19.$$

**深度学习里用的是互相关，不是卷积**，但术语上沿用了"卷积层"这个叫法。

**为什么可以这样替换**：核是**学出来的**。用互相关学到的核，与用卷积学到的核
恰好是翻转关系；两者对应的网络在预测时输出相同。既然核不是人定的，用哪种运算没有区别。
书上说"如无特别说明，本书中提到的卷积运算均指互相关运算"。

**实践含义**：看到"卷积"两个字时，默认按互相关理解，除非是在信号处理的语境里。

### 1.3 手写 `corr2d`

```python
def corr2d(X, K):
    h, w = K.shape
    Y = torch.zeros(X.shape[0] - h + 1, X.shape[1] - w + 1)
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            Y[i, j] = (X[i:i+h, j:j+w] * K).sum()
    return Y
```

**三件事**：
- **输出形状**要按公式先算对
- **窗口切片的起点是 `[i:i+h, j:j+w]`**，不是 `[i:i+h+1]`
- **`(X_window * K).sum()`** 是"按元素乘再求和"，不会自动降维

**双重 for 循环慢，但这一章不关心性能**——它是理解运算的方式。框架的实现
`nn.Conv2d` 走的是高度优化的底层，B16 才用。

## 2 卷积层

### 2.1 从运算到层

`nn.Conv2d(in_channels, out_channels, kernel_size, ...)` 就是一个卷积层。
它比 `corr2d` 多三件事：

| 多出来的 | 说明 |
|---|---|
| **可学习的核** | 核是 `nn.Parameter`，初始化为随机，跟着训练更新 |
| **通道维** | 输入输出都是 4 维 `(batch, channels, h, w)` |
| **偏置** | 每个输出通道加一个标量偏置 |

**输入通常是 4 维**：

```
(batch_size, channels, height, width)
```

一张灰度图是一批里有 1 张、1 个通道：`(1, 1, H, W)`。彩色图 `(1, 3, H, W)`。

**PyTorch 也接受 3 维输入**（`(C, H, W)`），当作"没有批量"处理。所以：

| 输入形状 | 结果 |
|---|---|
| `(H, W)` | 报错 `Expected 3D (unbatched) or 4D (batched) input to conv2d` |
| `(C, H, W)` | 可以，输出 `(out_ch, H', W')` |
| `(N, C, H, W)` | 可以，输出 `(N, out_ch, H', W')` |

**最容易搞混的是 2 维**——它被当成"没有通道"，而不是"没有批量"。
传一张 `(28, 28)` 的灰度图会报错，要写成 `(1, 1, 28, 28)`。

### 2.2 一个卷积层能不能学到东西

书上用一个边缘检测的例子说明：核固定成 `[[1, -1]]` 时，卷积层输出非零的地方就是
"左右相邻像素差异大"的位置——那是**竖直边缘**。

把核换成可学习的，然后让它逼近这个目标：训练之后学出的核就能检测边缘。
这说明**卷积核能学到有意义的局部模式**，而且不需要人告诉它"边缘"是什么。

## 3 填充与步幅

### 3.1 填充

**问题**：每做一次卷积，输出就缩小 `k_h - 1`（高）与 `k_w - 1`（宽）。堆几层之后
图像就没了。

**做法**：在输入四周补 0（**填充**，padding）。设高两侧一共补 $p_h$ 行、宽两侧补 $p_w$ 列：

$$(n_h - k_h + p_h + 1)\times(n_w - k_w + p_w + 1).$$

**要使输入输出同尺寸**，取 $p_h = k_h - 1$、$p_w = k_w - 1$。核是奇数时两侧均分。

**为什么常用奇数核**（1、3、5、7）：这样两侧填充数相等，输出 `Y[i, j]` 恰好以输入
`X[i, j]` 为中心。偶数核只能一侧多补一格，中心不在像素上。

### 3.2 步幅

**步幅**（stride）是窗口每次滑动的距离。默认 1，即逐格滑。

高上步幅 $s_h$、宽上 $s_w$ 时：

$$\left\lfloor\frac{n_h - k_h + p_h + s_h}{s_h}\right\rfloor \times
  \left\lfloor\frac{n_w - k_w + p_w + s_w}{s_w}\right\rfloor .$$

**注意公式里是 `+ s` 不是 `+ 1`**——分子在算"能放几个窗口"，除完取整。

**用途**：步幅大于 1 是**降低分辨率**的另一种手段（另一种是池化）。卷积核 2、步幅 2
时，输出尺寸大约减半。

**默认值**：`padding=0`、`stride=1`。

## 4 多输入与多输出通道

### 4.1 多输入通道

输入有 $c_i$ 个通道时（例如彩色图 3 个），**每个通道配一个核数组**，核的形状是
$c_i\times k_h\times k_w$。

**运算**：每个通道各自做互相关，再把 $c_i$ 个结果**按元素相加**，得到一个二维输出。

**为什么相加**：每个通道代表一种"视角"（红、绿、蓝），卷积要把它们合成一个响应。
相加之后通道维消失——所以**多输入、单输出的结果是二维的**。

```python
def corr2d_multi_in(X, K):
    # X: (c_i, h, w)   K: (c_i, kh, kw)
    return sum(corr2d(x, k) for x, k in zip(X, K))
```

**`zip(X, K)`** 把 X 与 K 的第 0 维（通道维）配对。`sum(...)` 从整数 0 开始加，
所以第一个元素是 `0 + corr2d(...)`，结果类型正确。

### 4.2 多输出通道

要得到 $c_o$ 个输出通道，就对**每个输出通道各准备一组** $c_i\times k_h\times k_w$ 的核。
整体核形状：

$$(c_o,\ c_i,\ k_h,\ k_w).$$

```python
def corr2d_multi_in_out(X, K):
    # X: (c_i, h, w)   K: (c_o, c_i, kh, kw)
    return torch.stack([corr2d_multi_in(X, k) for k in K])
```

**遍历 `K` 的第 0 维**（输出通道维），每次用一组 $c_i\times k_h\times k_w$ 的核，
结果堆成一个 $c_o\times h'\times w'$ 的张量。

**通道数的含义**：

| 维度 | 含义 |
|---|---|
| 输入通道 $c_i$ | 上一层给了几种"特征图" |
| 输出通道 $c_o$ | 这一层要提取几种"模式" |

**参数个数** = $c_o \times c_i \times k_h \times k_w + c_o$（偏置）。

### 4.3 1×1 卷积

核是 $1\times 1$ 时，输出与输入同高宽，运算变成**"同一位置上跨通道的加权和"**：

$$Y_{o,i,j} = \sum_{c=1}^{c_i} K_{o,c} \cdot X_{c,i,j} + b_o .$$

**这等价于一个全连接层**：把通道维看作特征维、把每个空间位置看作一个样本，
就是 $c_i \to c_o$ 的全连接。

```python
def corr2d_multi_in_out_1x1(X, K):
    c_i, h, w = X.shape
    c_o = K.shape[0]
    X = X.reshape(c_i, h * w)
    K = K.reshape(c_o, c_i)
    Y = K @ X
    return Y.reshape(c_o, h, w)
```

**用途**：**在不改变高宽的前提下调整通道数**。通道数决定模型的表达能力，
1×1 卷积是"升降通道"最便宜的手段——B17 的 NiN 与 GoogLeNet 大量用它。

## 5 池化层

### 5.1 两种池化

**池化**（pooling）也在输入上滑窗口，但**不乘核**，直接取窗口内的统计量：

| 类型 | 输出 | 用途 |
|---|---|---|
| **最大池化** | 窗口内最大值 | 保留最强响应（最显著的边缘、纹理）|
| **平均池化** | 窗口内均值 | 保留整体强度 |

书上的例子：2×2 最大池化对 `[[0,1,2],[3,4,5],[6,7,8]]` 得到 `[[4,5],[7,8]]`。

```python
def pool2d(X, pool_size, mode="max"):
    p_h, p_w = pool_size
    Y = torch.zeros(X.shape[0] - p_h + 1, X.shape[1] - p_w + 1)
    for i in range(Y.shape[0]):
        for j in range(Y.shape[1]):
            window = X[i:i+p_h, j:j+p_w]
            Y[i, j] = window.max() if mode == "max" else window.mean()
    return Y
```

**与 `corr2d` 的结构完全相同**，唯一区别是"按元素乘再求和"变成"取 max/mean"。

### 5.2 池化为什么有用

书上举了一个例子：卷积层检测到某个模式后，如果模式在图上**平移了一个像素**，
最大池化仍然输出同样的结果——因为窗口里的最大值没变。

**这叫平移不变性**（更准确地说是"局部平移鲁棒性"）。它让网络对物体位置的细微变化
不敏感。

### 5.3 池化的默认步幅

**`nn.MaxPool2d(3)` 的默认步幅等于池化窗口大小**（这里是 3）。这与卷积层不同——
卷积层的默认步幅是 1。

**所以池化层默认就会降尺寸**：`MaxPool2d(2)` 让高宽各减半。

**填充与步幅的用法与卷积相同**，公式也一样。

### 5.4 多通道：分别池化

**这是与卷积最关键的区别**：

| 运算 | 多通道时怎么做 | 输出通道数 |
|---|---|---|
| **卷积** | 各通道结果**相加** | 由核的 $c_o$ 决定（可以变）|
| **池化** | 各通道**分别**池化 | **等于输入通道数**（不变）|

**池化没有可学习的参数**，也不改变通道数。它只是"在每个通道内降尺寸"。

## 6 特征图与感受野

**特征图**（feature map）：卷积层的输出。它是对输入在空间维度上某一级的表征。

**感受野**（receptive field）：影响输出中某个元素的前向计算的**所有输入区域**。

**例**：3×3 输入 → 2×2 核 → 2×2 输出。输出 `Y[0,0]` 的感受野是输入左上角 2×2 那块。

**堆两层之后**：再对 2×2 的输出做一次 2×2 卷积得到 1 个元素。它的感受野覆盖了
全部 9 个输入元素。

**这就是深层网络的意义**：层数越多，单个输出元素看到的输入范围越大，
于是能捕捉更大尺度的特征。B17 的 VGG、ResNet 靠堆层扩大感受野。

**经验公式**（本课不要求推导）：堆 $L$ 层 $k\times k$ 卷积（步幅 1、不填充）后，
感受野是 $1 + L(k-1)$。

## 7 实现会踩的坑

| 坑 | 症状 | 原因 |
|---|---|---|
| 传 2 维张量给 `nn.Conv2d` | `Expected 3D (unbatched) or 4D (batched) input` | 2 维被当成"没有通道"，要补成 `(1, 1, H, W)`（2.1）|
| 输出形状算错 | 所有后续层的形状都错 | 公式是 `(n - k + 1)`，不是 `(n - k)`（1.1）|
| 以为卷积层做的是"卷积" | 与手算结果符号相反 | 深度学习用的是互相关（1.2）|
| `X[i:i+h]` 写成 `X[i:i+h+1]` | 形状报错或越界 | 切片右端是开区间（1.3）|
| 多输入通道忘了相加 | 输出多一维 | 各通道结果要按元素加（4.1）|
| 以为池化会改通道数 | 形状对不上 | 池化**分别**处理各通道，通道数不变（5.4）|
| 以为 `MaxPool2d(2)` 步幅是 1 | 输出尺寸与预期不符 | 池化默认步幅 = 窗口大小（5.3）|
| 以为填充能让输出不变 | 输出尺寸与预期不符 | 要 `p = k - 1` 才同尺寸（3.1）|

## 自测题

1. 输入 5×5、核 3×3、无填充、步幅 1 时输出多大？加填充 1 之后呢？
2. 深度学习里的"卷积"实际是哪种运算？为什么可以用它代替真正的卷积？
3. 为什么常用奇数尺寸的卷积核？
4. 输入 3 通道、卷积层输出 16 通道、核 3×3。这个层有多少个参数？
5. 1×1 卷积等价于什么？它在网络里主要用来做什么？
6. 池化层的输出通道数是多少？与卷积层相比有什么区别？
7. 堆两层 3×3 卷积（无填充、步幅 1）后，感受野多大？

## 答案（做完再看）

**1.** 5×5、3×3 核 → 输出 `5-3+1 = 3`，即 3×3。填充 1 之后
`5-3+2+1 = 5`，仍是 5×5。

**2.** 实际做的是**互相关**（不翻转核）。可以代替真正卷积的原因是**核是学出来的**：
两种运算学到的核互为翻转，对应网络输出相同。核不是人定的，所以选哪个运算没区别。

**3.** 奇数核时两侧填充数相等（$p = k-1$ 是偶数，一半在左一半在右），输出
`Y[i,j]` 恰好以输入 `X[i,j]` 为中心。

**4.** $16 \times 3 \times 3 \times 3 + 16 = 432 + 16 = 448$。
公式是 $c_o \times c_i \times k_h \times k_w + c_o$。

**5.** 等价于一个**全连接层**（把通道维当特征、空间位置当样本）。主要用来
**在不改变高宽的前提下升降通道数**，控制模型的表达能力，同时比 3×3 卷积便宜得多。

**6.** 池化的输出通道数**等于输入通道数**——它对每个通道分别池化，不混合通道。
卷积层会混合通道（各通道结果相加），输出通道数由核的 $c_o$ 决定。

**7.** 第一层 3×3 后，每个元素看到 3×3；再一层 3×3，感受野是
$3 + (3-1) = 5$，即 5×5。公式 $1 + L(k-1) = 1 + 2\times2 = 5$。
